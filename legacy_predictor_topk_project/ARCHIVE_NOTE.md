# Legacy Predictor Top-K Project

该目录归档早期的 `Predictor-Guided Top-K Correction Agent` 项目线。

主要内容：

- `src/`: 纸面整理版源码
- `experiments/agent_mvp/`: CorrectionNet / Top-K selector / residual agent 实验
- `experiments/predictor_mvp/`: predictor 训练、校准和跨拓扑实验
- `experiments/paper_compare/`: 早期论文对比实验
- `experiments/yin2024_sim/`: Yin 2024 协议仿真原型
- `configs/`, `tests/`, `notebooks/`: 该旧项目的配置、测试和笔记本

当前论文主线不再维护该项目。主线代码请看仓库根目录下的 `sa_hmarl/`。
